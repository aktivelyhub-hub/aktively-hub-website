# Aktively Hub website

Static GitHub Pages website. Edit HTML and `assets/style.css` / `assets/main.js`.

## Content rules

- SIENTE, OLER, Caveman, MTN, FanMilk, Tampico and Black Rock examples are self-initiated spec work, not commissioned-client evidence.
- Slide In and a law firm are confirmed commissions by the owner. Their approved media and publication scope still need to be supplied; do not invent results or testimonials.
- Do not use Whole Beauty or Ananse media as public portfolio material. Whole Beauty's proposal can inform internal pitch structure.
- Do not present unfinished footage as a finished film. FanMilk video is withheld pending finishing verification.
- CRM and invoice tools are prototypes; do not imply live shared storage or automated notifications.
- Tampico's video is in the repository ROOT, not assets/. Preserve its working reference.

## Resource workflow

Google Drive holds original resources. GitHub holds the deployed website source. These are separate copies, not an automatic two-way sync. Use the owner-approved Aktively Drive folder guide to locate originals. Check provenance and completion before adding assets. Keep source snapshots and the change/resource register in Drive after website updates. Do not embed private Drive links or confidential source documents in public pages.

## Local preview and checks

Run `python -m http.server 8766 --bind 127.0.0.1` from this folder. Check all four pages, menu, contact links and video playback. Use the accompanying workspace link checker before publishing. GitHub Pages deployment must be verified after pushing.
